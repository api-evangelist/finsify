# Finsify

> Finsify Hub is a bank-data aggregation service for Southeast Asia. Its RESTful API gives partners access to end-user banking data — account balances, account status, and categorized transaction history — across 50+ bank and statement services in 15 countries. Partners include Money Lover, Money Paper, Ngan Luong, and Bao Kim.

Authentication is static header credentials: a Client-Id on every request plus exactly one secret (Service-secret for web/backend, App-secret for mobile). A short-lived connection token (POST /token) authorizes the end-user's bank login flow. API base URL: https://api.finsify.com/v2. No OAuth; no idempotency; the transaction endpoint filters by account_id and a from_date/to_date window (no pagination). Errors are JSON with an error name plus HTTP status. Webhooks push new-transaction and login-status-change events.

- [Finsify Hub API](https://api.finsify.com/v2): Bank aggregation REST API — customers, connection tokens, accounts, transactions, login management.
